# Windows 介面互動預覽

用瀏覽器開啟 index.html 即可。HTML 已內嵌圖示、提示聲與測試截圖，不需要安裝工具或連上 Tailscale。

左側切換日常面板、設定、最近辨識、常用詞、修正學習、保留錄音、配對、第一次使用、托盤、浮動島與圖示。右側切換連線／錄音／辨識情境，或試聽開始兩下、結束一下的敲擊聲。設定頁可捲動，固定保留返回與儲存按鈕。

這是 UI 模擬，不會錄音、寫入系統剪貼簿、登入帳號、修改 Windows 或安裝程式。示範詞庫與設定只存在本次頁面；「重設預覽」恢復初始內容。

## 來源與界線

- 依據 Windows 1.1.5，來源版本 a9f417636c8bdba3f0b6314ea87fa49199ad0f74 的 win/voice-input-tray.ahk、voice-input-style.ahk、voice-input-auth.ahk、voice-input-core.ahk。
- 直接內嵌該版本四個 ICO 與開始／結束 WAV。浮動島以相同正弦時間與三柱基線模擬，動畫不代表音量。
- 「實際程式截圖」取自 Windows 1.1.5 安裝後的 CI 驗證，全部為合成測試資料。浮動島圖片外側為測試桌面。
- App 面板、選單和對話框模擬現有行為；Windows 系統設定、檔案總管及外部網站以「示意」標示，不宣稱是逐像素重建。
- HTML 本身不代表原生 App 修改、新版本發布或實機收音／輸入法驗收。

預覽自動縮放以容納桌面；「原尺寸」顯示 520 × 660 的 App 用戶區域。支援鍵盤焦點、對話框 Tab 範圍、Esc 與系統減少動態偏好。
